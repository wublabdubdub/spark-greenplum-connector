# CN2 端口平移映射设计

## 一、目标

为 `its-ymatrix` connector 增加 CN2/Nginx 场景下的端口平移能力。Spark executor 在每台 YARN 机器上使用相同的本地端口段，MDB/YDB segment 则通过同一个 CN2 发布 IP 的不同端口段访问不同 Spark 机器。

本次只实现最新参数格式，不兼容上一版 `executorIP=发布IP:端口段` 的同端口映射格式。未配置 `server.publish.mapping` 时，connector 继续使用原有的 executor 本机地址和 `server.port` 或随机端口，不影响普通网络场景。

## 二、网络模型

当前环境约定如下：

| Executor 内网 IP | CN2 发布地址 | CN2 发布端口 | Spark 本地端口 | 转发方式 |
|---|---|---|---|---|
| `172.26.32.28` | `10.150.0.5` | `20101-20110` | `20111-20120` | Nginx 端口平移 |
| `172.26.32.113` | `10.150.0.5` | `20111-20120` | `20111-20120` | CN2 直接访问，不经过 Nginx |
| `172.26.32.114` | `10.150.0.5` | `20121-20130` | `20111-20120` | Nginx 端口平移 |

Nginx 不监听 `172.26.32.113:20111-20120`，因此不会与 113 上的 Spark executor 冲突。

## 三、参数格式

参数名保持为 `server.publish.mapping`，每个映射项使用以下格式：

```text
<executor内网IP>=<CN2发布IP>:<发布端口起始>-<发布端口结束>-><本地端口起始>-<本地端口结束>
```

完整示例：

```scala
.option(
  "server.publish.mapping",
  Seq(
    "172.26.32.28=10.150.0.5:20101-20110->20111-20120",
    "172.26.32.113=10.150.0.5:20111-20120->20111-20120",
    "172.26.32.114=10.150.0.5:20121-20130->20111-20120"
  ).mkString(",")
)
```

旧格式没有本地端口段，语义不完整，本版本遇到旧格式时直接抛出参数错误。

## 四、端口选择与换算

Connector 根据 executor 探测到的内网 IP 查找映射项，只在该映射项的本地端口段中启动 gpfdist 服务。

本地端口选定后，按端口在范围中的位置换算发布端口：

```text
发布端口 = 发布端口起始值 + 本地端口 - 本地端口起始值
```

例如，`172.26.32.28` 上的 gpfdist 选中本地端口 `20114`：

```text
发布端口 = 20101 + 20114 - 20111 = 20104
gpfdist URL = gpfdist://10.150.0.5:20104/output.pipe
```

MDB/YDB segment 的访问链路为：

```text
MDB/YDB segment
  -> 10.150.0.5:20104
  -> 172.26.32.113:20104
  -> Nginx
  -> 172.26.32.28:20114
  -> Spark executor gpfdist
```

## 五、源码结构

`ServerPublishMapping.scala` 负责：

- 解析新参数格式。
- 保存发布主机、发布端口段和本地端口段。
- 校验端口范围和端口数量。
- 根据本地端口计算发布端口。

`GPOptionsFactory.scala` 负责：

- 读取 `server.publish.mapping`。
- 根据 executor 内网 IP 返回对应的发布绑定配置。
- 在配置映射时拒绝同时配置固定 `server.port`。
- 未配置映射时返回原始网络行为。

`PortBinder.scala` 继续负责在指定范围内逐个尝试本地端口。本次传入的是本地端口段，不是发布端口段。

`RMISlave.scala` 负责：

- 在本地端口段启动 gpfdist。
- 读取 gpfdist 实际绑定的本地端口。
- 将本地端口换算成发布端口。
- 使用发布 IP 和发布端口生成外部表 `LOCATION` 所需的 gpfdist URL。

RMI 内部通信地址和 `PartitionControlBlock.nodeIp` 不做修改。

## 六、参数校验和错误处理

配置映射时执行以下校验：

- 每个端口必须在 `1-65535` 范围内。
- 端口段起始值不能大于结束值。
- 发布端口段与本地端口段包含的端口数量必须相同。
- 同一个 executor 内网 IP 不能重复配置。
- executor 实际探测 IP 必须存在于映射表中。
- `server.publish.mapping` 不能与非零 `server.port` 同时配置。
- 本地端口段全部被占用时，任务失败并显示耗尽的端口范围。

每台机器的本地端口段包含 10 个端口，因此一台机器最多同时提供 10 个占用独立端口的 gpfdist 服务。端口池容量不足时不使用范围外随机端口。
