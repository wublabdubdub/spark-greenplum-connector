# CN2 端口平移映射 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Spark executor 在统一的本地端口段启动 gpfdist，同时向 MDB/YDB 发布经过 CN2/Nginx 平移后的 IP 和端口。

**Architecture:** `ServerPublishMapping` 解析每台 executor 的发布端口段和本地端口段，并负责按端口位置进行一一换算。`RMISlave` 只在本地端口段绑定服务，再使用换算后的发布端口构造 gpfdist URL；未配置参数时继续走原始路径。

**Tech Stack:** Scala 2.12、Spark DataSource V2、Java `HttpServer`、Maven、Scala 标准断言

- [ ] **Step 1: 将映射模型拆分为发布端口段和本地端口段**

核心模型改为：

```scala
final case class PortRange(start: Int, end: Int) {
  require(start >= 1 && start <= 65535, s"Invalid port range start: $start")
  require(end >= 1 && end <= 65535, s"Invalid port range end: $end")
  require(start <= end, s"Invalid port range: $start-$end")

  def ports: Iterator[Int] = (start to end).iterator
  def size: Int = end - start + 1
  def contains(port: Int): Boolean = port >= start && port <= end
  override def toString: String = s"$start-$end"
}

final case class PublishEndpoint(
    publishHost: String,
    publishPortRange: PortRange,
    localPortRange: PortRange) {
  require(
    publishPortRange.size == localPortRange.size,
    s"Publish port range $publishPortRange and local port range $localPortRange must contain the same number of ports"
  )

  def publishPortFor(localPort: Int): Int = {
    require(localPortRange.contains(localPort), s"Local port $localPort is outside configured range $localPortRange")
    publishPortRange.start + localPort - localPortRange.start
  }
}

final case class PublishBinding(localHost: String, endpoint: Option[PublishEndpoint]) {
  def publishHost: String = endpoint.map(_.publishHost).getOrElse(localHost)
  def localPortRange: Option[PortRange] = endpoint.map(_.localPortRange)
  def publishPortRange: Option[PortRange] = endpoint.map(_.publishPortRange)
  def publishPortFor(localPort: Int): Int = endpoint.map(_.publishPortFor(localPort)).getOrElse(localPort)
}
```

- [ ] **Step 2: 只解析新格式并拒绝旧格式**

解析器必须接受：

```text
172.26.32.28=10.150.0.5:20101-20110->20111-20120
```

解析顺序为：按 `=` 分离 executor IP，按 `->` 分离发布端点和本地端口段，再按发布端点最后一个 `:` 分离发布主机与发布端口段。缺少 `->`、端口非法、范围长度不同、executor IP 重复时抛出 `IllegalArgumentException`。

- [ ] **Step 3: 调整绑定解析结果**

`GPOptionsFactory.resolvePublishBinding` 改为：

```scala
serverPublishMapping.get(localHost) match {
  case Some(endpoint) => PublishBinding(localHost, Some(endpoint))

    throw new IllegalArgumentException(...)
  case None => PublishBinding(localHost, None)
}
```
